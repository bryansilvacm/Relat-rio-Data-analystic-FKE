# 📊 Relatório-Data-analystic-FKE

Desafio de Projeto Criando um relatório de Vendas e Lucro Data analystic - Bootcamp Analise de dados com Power BI - DIO

---

## 🎯 Objetivos:
O objtivo desse projeto é criar um relatório de vendas e lucros aplicando conceitos de analise de dados e pensando na experiência do usuário.

---

## 📌 Introdução:
Esse projeto consiste em um relatório interativo, intuitivo e eficiênte, pensando na disposição dos elementos para uma melhor harmonia, cores e visuais concistentes e modernos, graficos e informações relevantes para que o usuário possa obter insights realmente necessários.

---

## 🛠️ Desenvolvimento:
A primeira etapa realizada foi definir a disposição dos gráficos e elementos para uma melhor harmonia e visualização. Foi definido como os elementos seriam posicionados, para isso pensamos em conceitos básicos de proporção aurea, as páginas foram divididas em blocos e cada bloco contém gráficos que se complementam e fazem sentido um com o outro.

As cores também são importantes para uma melhor experiência, um bom contraste e cores que combinem são essenciais para uma ótima visualização e para diminuir o cansaço da vista.

A primeira página do relatório contém os principais informações sobre as vendas:

** Cards:**
*  Total de faturamento;
*  As unidades vendidas;
*  Total em descontos aplicados;
*  Total de custos diretos com os produtos;

** Gráficos:**
*  Relação de vendas mensais;
*  Vendas por segmento;
*  Vendas por produto (TOPN com a hierarquia dos produtos mais vendidos);
*  Vendas por países.

A segunda página possui mais detalhes sobre as vendas trimestrais, um gráfico de linhas temporal representando a relação Custo x Vendas x Lucro e um agrupamento dos descontos em niveis, alto, médio e baixo, onde podemos analisar a quantidade de vezes que cada faixa de desconto foi aplicada.

Na terceira página temos mais detalhes dos lucros, podemos observar que existe uma margem negativa um pouco preocupante, e ao lado um grafico de funil com os produtos que mais geraram prejuízo. Possui também as instancias de vendas linha a linha com todas as informações para analise mais profunda, onde podemos perceber quais vendas geraram um lucro negativo.

Todas as páginas possuem botões para navegabilidade entre elas, segmentação e filtros.

**As vendas dos produtos cresceram ao longo do tempo e com isso o lucro também cresceu, porém o custo dos produtos são relativamente altos, com isso os lucros não são tão expressivos. Esse número caí ainda mais quando observamos que descontos são aplicados com frequência e em alguns casos são descontos muitos altos, o que tem gerado em algumas vendas uma margem negativa, um total de -777 mil reais. 
Levando em consideração que os dados fornecidos para análise são ligados somente ao custo dos produtos, sabemos que esse lucro é bruto, ou seja, desse montante ainda deverá ser descontado os custos administrativos, salários e etc. Isso agrava ainda mais o cenário.**

## 🏁 Conclusão:

O projeto pôde ainda abranger a parte de análise dos dados, resultando na compreensão de que o cenário atual da empresa é estável porém precisa de uma intervensão para diminuir custos e descontos para aumentar os lucros, pois apesar do crescimento das vendas os gastos administrativos não estão inclusos nos dados fornecidos e pode ser um fator consumidor de uma boa parte do lucro bruto, obtendo assim um lucro liquido muito baixo ou quase nulo.**
